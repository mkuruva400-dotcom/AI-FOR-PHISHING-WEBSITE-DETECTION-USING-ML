Multi-Tier Defense Architecture

The platform implements a defense-in-depth framework structured into four independent inspection layers:

Tier 1: URL Intelligence

24 numerical features capturing lexical length, token counts, Shannon entropy, TLD risk, and DGA markers.

Tier 2: Ensemble AI & ANN

6-way classification: Random Forest, Decision Tree, SVM, Logistic Regression, XGBoost, and Keras Deep Learning ANN.

Tier 3: Isolated DOM Inspection

Safe headless inspection checking password action targets, hidden iframes, external link ratios, and brand spoofing.

Tier 4: OpenCV Visual Matching

Perceptual dHash and color histogram correlation against legitimate brand targets to detect unauthorized impersonation.

Essential Viva Voce Questions

Answer: Static blacklists (like Google Safe Browsing or PhishTank) rely on reactive manual reporting and crawler verification, resulting in a detection lag of 4 to 24 hours. Because the average lifespan of a modern phishing site is under 4 hours (zero-day phishing), blacklists miss up to 60% of active campaigns. Our AI engine evaluates structural, lexical, behavioral, and visual characteristics in real-time (<50ms), detecting brand-new zero-day attacks even if the domain was registered minutes earlier.

Answer: Traditional machine learning models output a probability score without explanation, making it impossible for security analysts to trust borderline decisions. Using Shapley Additive exPlanations (SHAP) derived from cooperative game theory, our system calculates the exact marginal contribution of each feature to the prediction score. It visually shows *why* a URL was flagged (e.g. "+0.331 due to missing HTTPS, +0.124 due to high-risk .xyz TLD"), providing verifiable evidence for forensic auditing.

Answer: "Quishing" (QR Code Phishing) is an emerging social engineering attack where malicious URLs are encoded inside QR codes printed on physical flyers, parking meters, or embedded in email PDFs to bypass traditional email secure gateways. Our system uses OpenCV's cv2.QRCodeDetector with Otsu thresholding to decode the matrix payload and immediately routes the hidden URL into our multi-tier AI evaluation pipeline.

Answer: Different algorithms possess unique inductive biases: Decision Trees offer interpretable rules, Logistic Regression establishes a linear baseline, Support Vector Machines maximize margins in hyperplanes, Random Forest reduces variance through bagging, XGBoost minimizes residuals through gradient boosting, and Keras ANN learns high-dimensional non-linear interactions. Benchmarking all 6 enables empirical proof of the best architecture for cybersecurity tasks and allows deploying a high-reliability weighted Ensemble.

Answer: Suspicious URLs are never opened in the user's browser where client-side exploits, drive-by downloads, or session hijacking could occur. Instead, an isolated backend crawler performs a stream-capped HTTP request (max 1MB, 3-second timeout, no JavaScript execution) inside a sandboxed Python session, inspecting only raw HTML tags and headers.
